# type_asist - Autocomplete & Spellchecker Engine

A C++ based text assistance system providing **word autocomplete and spell correction** using efficient data structures and string-matching algorithms.

### Features

* Word autocomplete using **Trie**
* Spell checking and correction
* **N-gram inverted index** for candidate generation
* **Levenshtein distance** for ranking
* **Keyboard distance** for typing errors
* Top-K suggestions
